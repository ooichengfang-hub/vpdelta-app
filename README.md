# VP Delta

Live volume / delta / liquidation profile chart for Binance USDT-M futures, as a single-page web app.

- Public Binance market data only (REST klines, kline + forceOrder WebSocket streams). No account, no API keys.
- Delta is approximated from candle taker-buy volume; liquidations are a live sample collected while the page is open.
- iPhone: open the site in Safari → Share → Add to Home Screen.

Not financial advice.
